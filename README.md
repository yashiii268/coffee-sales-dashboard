# coffee-sales-dashboard
I developed and comprehensive MS excel dashboard for coffee sale sorting data and creating multiple pivot tables. This process involved varies stages like data processing , and vizualization.
## Dataset used
- <a href="https://github.com/mochen862/excel-project-coffee-sales/blob/main/coffeeOrdersData.xlsx">dataset</a>
## Questions (KPIs)
- compare sales and orders using Timeline and Slicers.
- which month got the highest sales?
- contribution to orders acoording to country.
- how much coffee roast type(s) got sold over a certain time period?
- sales chart according to size of coffee ordered.
- list of top 10 buyers.
- pattern of purchase by loyalty card holders.
